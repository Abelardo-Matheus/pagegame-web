# PageGame (web)

Versão web/celular do PageGame: um bichinho (ou o saltador) que come as
letras dos artigos da Wikipédia.

- Jogar: abra `mobile/` (ou a raiz, que redireciona).
- Android: `PageGame.apk` (versão de teste).

Gerado a partir do repositório principal `pagegame` (privado). Não edite
aqui: edite lá e publique de novo.
